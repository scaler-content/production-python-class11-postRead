The big picture

  
What you built today

  
You started with a Python program that read files one after another and had a clean seam around its vendor. You finished with a second, parallel path: Spark reads the old system’s Parquet export and the CSV and JSON sources, applies the same rules as column expressions, writes curated and rejected tables, and prepares a small capped list for an AI step that happens later, in Python. Parity checks prove that the two paths agree.

Rebuild it

  
From one Python process to a proven Spark slice, step by step

  
Each step depends on the one before it. Click the steps in the order you would do this work yourself, first to last.

  

    

    

    

    

  

  
Why this order?You cannot judge what you cannot read, so the schema comes first. Parsing in expressions needs strings to parse, and a lazy plan has to be understood before the slice can be written safely. Parity comes after the slice exists, and the model estimate comes last because it needs the candidate count the slice produced.

Choosing the tool

  

  

    
What do you need?UseNote

    
One column formula Spark can planA native expression (F.when, F.upper, F.regexp_replace)0.19 s on 197,939 rows

    
A rule nothing native can sayA pandas UDF, then a Python UDF0.96 s and 1.89 s. The plan shows BatchEvalPython

    
A date that may be badF.try_to_timestamp with a patternNull, not a crash. to_date raises in ANSI mode

    
Strip a value like Python doesstrip() in judge.pyF.trim removes spaces only

    
A text column from a fileAn explicit all-string schemainferSchema changes with the data

    
A JSON list over several linesmultiLine=TrueWithout it you get _corrupt_record

    
One table feeding several resultscache()Otherwise each action reads the file again

    
A result to look atcount(), take(n), limit(n)Not an unrestricted collect()

  

  

  
Transformation or action

  

  

    
KindExamplesWhat happens

    
Transformationselect, filter, withColumn, withColumnRenamed, drop, join, groupByAdds to the plan. 0 jobs

    
Actioncount, show, take, collect, write.parquetRuns the plan. Runs it again unless cached

    
ShuffleA window, a group-by, a joinShows as Exchange in explain(). The expensive step
